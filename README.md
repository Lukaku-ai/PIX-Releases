# PIX — Poco Instruments & eXtensions

필요할 때 꺼내 쓰는 Windows 도구 모음입니다. PC 정보, 빠른 원격접속(RDP/OpenSSH/PuTTY), 파일 검색, 파일 점유 추적을 제공합니다.

## 설치 및 업데이트

[최신 릴리스](https://github.com/Lukaku-ai/TUJ-Releases/releases/latest)에서 PIX_Installer_0.0.8.exe를 실행하세요. 기존에 사용하던 .tujlic 라이선스와 사용자 데이터는 업데이트에서도 유지됩니다. 기존 PC는 Main부터 업데이트하며 선택한 모듈도 갱신됩니다.

0.0.8은 트레이 우클릭 메뉴에 `화면 새로고침`을 추가합니다. 화면 표시가 흐트러졌을 때 Main의 배치와 실행 중인 내장 모듈 창의 연결·그리기를 다시 적용합니다. 모듈을 다시 실행하지 않아 입력·작업 상태를 유지하며, 화면을 수동으로 복구하는 기능입니다. 장시간 대기 후 표시 문제가 생기는 원인을 해결했다고 보장하지는 않습니다.

0.0.7은 완료된 업데이트 알림을 자동으로 읽음 처리하고, 알림 센터에 PIX의 전체 이름을 표시합니다. 기존 라이선스와 구버전 설치 호환성은 유지합니다.

0.0.6은 다운로드마다 고유한 캐시 경로를 사용해 같은 파일명이 남아 있어도 업데이트가 막히지 않도록 하며, 빠른 원격접속의 연결 버튼·즐겨찾기 우클릭 메뉴·카드 호버 상태를 정리합니다.

0.0.5는 기존 TUJ 데이터 폴더의 이동·삭제 권한이 없지만 읽기는 가능한 경우, 남은 데이터를 PIX로 복사하고 내용을 검증합니다. 삭제하지 못한 구 파일은 보존하며 이전 완료 뒤 오래된 설정이나 업데이트 잠금을 다시 사용하지 않습니다. 읽기 또는 새 폴더 쓰기까지 거부되면 원본을 보존하고 오류를 안내합니다.

0.0.4에서 AppData/Local/TUJ 접근 거부로 설치가 실패했다면 새 설치기로 복구 설치하세요. 기존 프로그램·TUJ 폴더·라이선스·프로필을 먼저 삭제하지 마세요. 설치 실패 진단은 %TEMP%/PIX/Updates/main-update.log에 기록합니다.

설치 폴더·설정·프로필·색인·캐시는 PIX 경로를 사용합니다. 사용자 지정 다른 설치 폴더 이름은 유지합니다. 기존 설치와 라이선스 호환을 위해 GitHub 주소, 내부 식별자 및 TUJ_Setup.exe 다운로드 별칭은 유지합니다.

빠른 원격접속 카드는 별칭·주소·연결 버튼만 표시합니다. 즐겨찾기·정보·수정·삭제는 우클릭 메뉴에 있습니다. .NET/WPF 런타임이 모듈에 포함되며 OpenSSH/PuTTY 접속은 해당 클라이언트가 필요합니다.

이 저장소에는 공개 설치 및 모듈 배포 파일만 제공합니다. 소스, 라이선스 발급기, 개인키는 포함하지 않습니다. 2026-09-11 초기화 이후 0.0.1 라이선스는 계속 유효합니다.
