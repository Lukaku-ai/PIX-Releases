# PIX — Poco Instruments & eXtensions

필요할 때 꺼내 쓰는 Windows 도구 모음입니다. PC 정보, 빠른 원격접속(RDP/OpenSSH/PuTTY), 딥 파인드, 파일 점유 추적기를 제공합니다.

## 설치

[최신 릴리스](https://github.com/Lukaku-ai/PIX-Releases/releases/latest)에서 **PIX_Installer_0.0.9.exe**를 실행하고 소유자에게 받은 새 **.pixlic** 라이선스를 선택하세요.

**0.0.9는 이전 버전과 호환되지 않는 새 설치 기준입니다.** 기존 사용자는 이전 앱을 종료·제거하고 새 설치기와 새 라이선스로 다시 설치해야 합니다. 필요한 사용자 자료는 제거 전에 별도로 보관하세요. 이전 라이선스·패키지·설치 등록을 자동으로 이전하지 않습니다.

프로젝트·프로그램·데이터 경로와 내부 식별자를 PIX로 통일했습니다. Main과 세 공개 모듈은 0.0.9이며 이전 모듈은 사용하지 않습니다. 모듈에 .NET/WPF 런타임이 포함됩니다.

화면이 흐트러지면 **트레이 우클릭 → 화면 새로고침**을 사용하세요. 모듈을 다시 시작하지 않고 화면 연결·위치·그리기를 다시 적용합니다. 원격접속 카드의 즐겨찾기·정보·수정·삭제는 우클릭 메뉴에 있습니다. OpenSSH/PuTTY 접속에는 해당 클라이언트가 필요합니다.

이 저장소는 공개 설치 파일과 `.pixpkg` 모듈만 제공합니다. 소스·라이선스 발급기·개인키는 공개하지 않습니다. 다운로드에는 인터넷이 필요하며 라이선스 검증 서버는 없습니다.
